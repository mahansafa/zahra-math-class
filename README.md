# کلاس ریاضی مهندس زهرا تعویذی

وب‌سایت فارسی و راست‌به‌چپ برای آموزش ویدیویی ریاضی، مدیریت شاگردها و فروش دوره‌ها. طراحی صورتی ملایم و فونت بی‌نازنین.

## دانلود برای نصب روی سرور

**[دریافت بستهٔ نصب و کد از بخش Releases](https://github.com/mahansafa/zahra-math-class/releases)**

فایل `zahra-math-server-handoff.zip` شامل خروجی اجرایی مستقل، کد اوبونتو، کد اصلی و راهنمای فارسی است. نصاب بعد از استخراج، `START_HERE.html` را باز کند.

**هدف استقرار: اوبونتو ۲۴.۰۴ با معماری x86_64 و دامنهٔ اصلی با پسوند .ir.**

## قابلیت‌ها

- دوره‌ها و آپلود ویدیوی خصوصی، پخش با درخواست Range و واترمارک
- ساخت دستی حساب شاگرد، تعیین رمز و انتخاب دسترسی دوره‌ها
- ثبت‌نام دو مرحله‌ای شاگرد و نمایش خودکار در فهرست مدیریت
- فروشگاه دوره‌ها، قیمت‌گذاری مدیر، سبد خرید و محاسبهٔ مبلغ در سرور
- شماره کارت و نام مالک قابل ویرایش، ارسال اجباری متن یا تصویر رسید
- بررسی مالی و فعال‌کردن دسترسی بعد از تأیید پرداخت
- ورود مستقل مدیر و شاگرد، کنترل پخش هم‌زمان و بکاپ روزانهٔ دیتابیس

## فناوری‌ها

تایپ‌اسکریپت، ری‌اکت و Next.js؛ اجرای Node.js 24؛ پایگاه دادهٔ SQLite با WAL؛ Nginx و systemd روی لینوکس. ویدیوها و رسیدها خارج از پوشهٔ عمومی نگهداری می‌شوند.

## راهنمای نصب و توسعه

- [راهنمای نصب، انتقال اطلاعات و آزمون تحویل](INSTALL_FA.md)
- [کد نسخهٔ اوبونتو و ابزارهای استقرار](source-ubuntu.zip)
- [نتیجهٔ آزمون خروجی اجرایی](validation.json)

کد کامل نسخهٔ مستقل اوبونتو در `source-ubuntu.zip` قرار دارد؛ ابتدا آرشیو را استخراج و وارد پوشهٔ `source-ubuntu` شوید. این مخزن فایل‌های تحویل به نصاب و آرشیو کد را نگهداری می‌کند. برای توسعه، وابستگی‌ها را با نسخهٔ pnpm مشخص‌شده در `package.json` و lockfile نصب کنید، سپس build بگیرید. برای بسته‌بندی از ریشهٔ پروژه دستور زیر اجرا می‌شود:

</div>

```sh
pnpm install --frozen-lockfile
pnpm run build
node deployment/iran/package.mjs . work/iran-release
```

ابزار `prepare.mjs` برای تبدیل کد نسخهٔ اصلی در آرشیو `source-original.zip` است؛ روی کد اوبونتوی استخراج‌شده دوباره اجرا نشود. برای نصب معمول، خروجی آمادهٔ بخش Releases به build یا نصب npm روی سرور نیاز ندارد.

## وضعیت انتقال و آزمون

این مخزن و فایل‌های انتشار شامل اطلاعات واقعی شاگردها، رمزها، سفارش‌ها، رسیدها یا ویدیوهای فعلی نیستند. دریافت خروجی دیتابیس و فایل‌های خصوصی مبدأ و انتقال آن‌ها هنوز انجام نشده است؛ پیش از تغییر سرویس، بخش انتقال راهنما تکمیل شود. هیچ نصب روی سرور مقصد انجام نشده است.

خروجی اجرایی پس از استخراج با ۵۵ بررسی محلی API، شامل ۲۰۰ درخواست موازی کوچک برای ویدیوی خصوصی، آزمایش شده است. ظرفیت ۲۰۰ پخش واقعی، پهنای باند مقصد و رفتار مرورگر روی سرور مقصد هنوز بررسی نشده‌اند.

کنترل دستگاه از کوکی و مجوز پخش استفاده می‌کند و الزام یک IP ثابت یا قفل سخت‌افزاری نیست. واترمارک وجود دارد؛ DRM و سیاه‌شدن تضمینی اسکرین‌رکورد و ورود دومرحله‌ای مدیر پیاده نشده‌اند.

برای دسترسی داخلی، میزبانی و DNS مناسب داخل ایران لازم است؛ پسوند .ir به‌تنهایی دسترسی در تمام اختلالات شبکه را تضمین نمی‌کند. بکاپ موجود مربوط به دیتابیس است؛ بکاپ مستقل ویدیو و رسید و نسخهٔ خارج از سرور باید هنگام نصب تنظیم شود.

## انتشار عمومی

اطلاعات اتصال و شناسهٔ پروژهٔ میزبانی قبلی در نسخهٔ عمومی قرار نگرفته‌اند. کد و وابستگی‌های ثالث تابع مجوزهای مربوط به خود هستند؛ عمومی‌بودن این مخزن به‌تنهایی مجوز مستقلی برای اجزای ثالث صادر نمی‌کند.
